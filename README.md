#Snake Game 🐍

Snake Game is a classic console-based implementation of the popular arcade game, built using Python. This project allows players to control a snake's movement on a grid, consume food items, and grow in size while avoiding collisions with itself and the grid boundaries.

Features:
Interactive Gameplay: Use directional inputs (U, D, L, R) to guide the snake on the grid.
Dynamic Food Placement: Randomly generates food at new locations on the grid as the snake consumes them.
Game Over Logic: Ends the game if the snake collides with itself or the grid walls.
Customizable Grid Size: Easily change the grid dimensions for varied difficulty levels.
How It Works:
The game initializes a grid with walls, a snake starting position, and food items.
Players control the snake's movement using keyboard inputs.
The snake grows longer as it eats food, and the game continues until a collision occurs.
The board updates dynamically, displaying the snake's progress.
Technologies Used:
Python: Core programming language for the game logic.
Queue Data Structure: Manages the snake's body efficiently.
Getting Started:
Clone the repository.
Run the snake_game.py file in a Python environment.
Follow the on-screen instructions to play the game.
Applications:
A fun and nostalgic way to learn Python.
Demonstrates the use of data structures like queues in game development.
A great starting point for building more advanced games.
